# ⚡ OmniExtract AI

Умное веб-приложение на базе **Streamlit** для быстрого анализа, конспектирования и извлечения информации из различных источников.


## 🚀 Основные возможности

* **📺 YouTube:** Автоматическое извлечение субтитров из любых видео (обычные ролики, Shorts, трансляции) с поддержкой многоязычности.
* **🌐 Веб-статьи:** Интеллектуальная загрузка и очистка текстов с веб-страниц (с защитой от рекламного мусора).
* **📄 Документы:** Чтение и распознавание текста из файлов **PDF, TXT и Markdown**.
* **🧠 Мульти-провайдерный ИИ-хаб:** Поддержка облачных ИИ (**Groq, OpenRouter, OpenAI, DeepSeek, Google Gemini**, кастомные API) и локального запуска через **Ollama**. Приложение само динамически подгружает актуальный каталог моделей.
* **⚡ Готовые пресеты задач:** Генерация главных мыслей, детальных конспектов, глубоких FAQ, тестов для проверки знаний и пошаговых планов действий.
* **🔒 Безопасность:** Надежная изоляция API-ключей через файл `.env` с возможностью ввода личного ключа «на лету» в интерфейсе.
